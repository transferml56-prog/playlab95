WHAT'S IN THIS BUILD

22 animated players, custom routes, drag-and-drop formations, defensive assignments, passing, blocking, and basic coverage. This is a playable prototype, not a full physics-based football engine.

PLAYLAB 95 is an original, independently built prototype inspired by classic PC football play designers. Touch drawing and field panning on mobile. Run as a hosted webpage for full functionality.
